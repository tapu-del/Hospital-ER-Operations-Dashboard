# 🏥 Hospital ER Operations & Wait Time Dashboard

## Project Overview
Emergency Rooms (ERs) face critical challenges in managing patient flow and reducing wait times. This interactive Power BI dashboard was built to analyze ER operations, identify bottlenecks, and track patient satisfaction. 

## Tools & Skills Used
* **Power BI:** Data Modeling, DAX, Visualizations
* **Data Analysis:** Operational Efficiency, KPI Tracking
* **Design:** Clean UI with a healthcare-focused color palette

## Key Insights Explored
* **Patient Volume & Wait Times:** Tracked total patients and average wait times across different days of the week.
* **Patient Outcomes (Waterfall):** Analyzed the flow of patients (Admitted, Discharged, LWBS - Left Without Being Seen).
* **Satisfaction (Gauge):** Monitored overall patient satisfaction to ensure quality care.
* **Urgency Filtering:** Implemented a dynamic Slicer to filter the entire dashboard by triage urgency (Critical, High, Medium, Low).
